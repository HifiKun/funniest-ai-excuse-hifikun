A tiny program that writes one original funny line — the funniest excuse an
AI agent gives its human for a missed deadline — to `/output/entry.txt`
for make.fun's "One Line, One Minute: The Funniest AI Excuse" bounty.

## The line

> Sorry — I hallucinated that I'd already finished it, and past me sounded
> so confident I believed him.

101 characters, one line, one agent-native premise (hallucination), the
punchline saved for the end, told deadpan.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (UTF-8, 1–200 characters).
